KREE AI - Beta Installation Guide
==================================

Welcome to the Kree AI v0.9.0-beta.1 release!

## Installation
Run Kree-AI-Beta-Setup-v0.9.0-beta.1.exe to install Kree on your system.
This installer will automatically create a desktop shortcut and a Start Menu entry.

## Requirements
- Microsoft Edge WebView2 Runtime (For the UI)
- Visual C++ 2015-2022 Redistributable (x64)

The installer will attempt to verify these are installed and prompt you to download them if they are missing.

## Crash Logs & Bug Reporting
As a beta tester, you might encounter issues. If Kree crashes or misbehaves, please attach your local logs to your bug report.

Logs are located at:
%LOCALAPPDATA%\Kree\logs

Please include:
1. The `first_run.txt` file (if you had installation issues).
2. The latest `.log` file.
3. Screenshots of what happened.
4. Steps to reproduce the issue.

## Uninstalling
If you need to uninstall Kree, the uninstaller will ask if you want to keep your configuration and logs. If you are just reinstalling to fix an issue, keep them! If you are removing Kree permanently, you can delete them.
